# Support

Use [GitHub Issues](https://github.com/Johan070119/Grails-VsCode-Extension/issues)
for bug reports and feature requests.

Include the extension version, operating system, VS Code version, Grails version,
JDK version and the relevant output from **View → Output → Grails Language Server**.
For semantic-server problems, also include the corresponding **Grails Semantic**
output channel. Remove credentials, tokens and proprietary source before sharing logs.

Security vulnerabilities should follow [SECURITY.md](SECURITY.md) instead of being
reported publicly.
